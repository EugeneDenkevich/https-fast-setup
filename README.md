# HTTPS Fast Config
Help you to configure 

### STEPS:
1. Replace domain:
`task set-domain -- your-favorite-domain.app`

2. Switch to http for cert generation:
`task switch-http`

3. Test cert generation:
`task test-cert`

4. Run cert generation:
`task cert`

5. Switch https back:
`task switch-https`

6. Get cert info:
`task cert-info`
